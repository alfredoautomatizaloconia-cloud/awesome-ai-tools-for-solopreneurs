# Contributing

Thanks for contributing.

## Submission Rules
- Add only AI tools relevant to solopreneurs, operators, or small teams.
- Use direct non-affiliate links in this repo.
- Include a short practical one-liner.
- Include pricing if known.
- Prefer tools with clear business use cases.

## How To Submit
1. Fork the repository.
2. Edit `data/tools.json` and add your tool entry.
3. Run `npm run build:readme`.
4. Open a PR with evidence and rationale.

## Tool Entry Checklist
- `name`: tool name
- `githubUrl`: canonical non-affiliate homepage
- `oneLiner`: clear practical description
- `categoryLabel`: one category label
- `priceText`: e.g. `Free`, `Free + $20/month`, `$29 one-time`

## Rejections
PRs may be rejected if they include affiliate links, duplicate tools, generic marketing copy, or no practical value.
